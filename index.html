Find Help Near Me

Choose your county and the kinds of help you want. You will get links to your college, your county, and California.

Before you start: This tool does not apply for anything, does not save anything, and cannot tell you whether you qualify for any program. It points you to official websites so you can ask. Asking for help is a good first step.

For college staff: add your college’s information

Each college can add its own offices, programs, and websites so students see them first. Open this file in a text editor and find the block that starts with const COLLEGE. Fill in the name, the date you updated it, and (if you like) a county to choose automatically. Under topics, add items for each kind of help.

List offices and programs, not the names of people, because staff change. Use website links that start with https://. Leave a topic empty if your college does not offer that help.

topics: {
  food: [
    { label: "Basic needs center",
      url: "https://www.example.edu/basic-needs",
      note: "Student Services Building, Room 100" }
  ]
}

Topic names you can use: calfresh, food, internet, housing, health, mental, childcare, transport, legal, immigration, veterans, foster, jobs, money.
